I.1
Create a simple 'canvas of characters' of width <WIDTH> and height <HEIGHT>
Example (5 x 20 ; please create a bigger one)
####################
#                  #
#                  #
#                  #
#                  #
#                  #
####################


| sequence of input             | operation                                                              
|-------------------------------|------------------
| '#' x <WIDTH>                 | header border                                           
| ctrl-d                        | dublicate line                                      
| RET x <HEIGHT>                | insert <HEIGHT> lines                                           
| ALT-up-key x <HEIGHT - 1>     | multi-line editing / set multiple cursors
| '#' + ' ' x <WIDTH - 2> + '#' | multi-line editing / left and right border                                         
|                               | START PLAYING AROUND         
| Insert                        | change insert mode and overwrite mode         
|                               | create vertical horizontal and diagonal lines
|                               |   What distubrs creating diagonal lines? What could be a solution?
| ctrl-click x <NUMBER CURSORS> | Try out 'multi-cursor editing'
| ctrl-shift up|down            | Try out 'moving lines'	  
|                               |

II.2
Create: A table, structured information, command-line calls
II.2.1 Create a table like this:
 # |    description     |  name      | id    | value      |    
---|--------------------|------------|-------|------------|----
   |                    |            |       |            |    
   |                    |            |       |            |    
---|--------------------|------------|-------|------------|----
   |                    |            |       |            |    
   |                    |            |       |            |    
---|--------------------|------------|-------|------------|----
- just bigger
- Use the above learned control-characters
- New: "Column Mode" --> Hold Alt-Shift while using arrow keys
- See also "Menu:/Edit/Column Mode..."

II.2.2 Create structured information
- Convert the left into the right
apples              <item>apples</item>
bread               <item>bread</item>
onion       ---->   <item>onion</item>
banana              <item>banana</item>
pumpkin             <item>pumpkin</item>
- use these text lines:
apples 
bread  
onion  
banana 
pumpkin
garlic
tomatos

sugar

II.2.3 Create command-line calls
- Convert the left into the right
file01                    pandoc file01.docx -o file01.md

file11       ---->        pandoc file11.docx -o file11.md
